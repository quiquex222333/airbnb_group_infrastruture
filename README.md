# Airbnb Group Infrastructure

Repositorio de infraestructura usando AWS CDK.

## Contenido
- API Gateway
- Lambda
- Cognito
- DynamoDB
- EventBridge
- SQS

## Instalación
npm install

## Build
npm run build

## Deploy
cdk deploy

## Destroy
cdk destroy

## Requisitos
- AWS CLI configurado
- CDK instalado

## Nota
Este repo depende del repo airbnb_group_services.
